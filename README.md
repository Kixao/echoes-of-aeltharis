# Echoes of Aeltharis — Alpha Version 1

Based on development build EoA-v0.0.46.

Open `index.html` in a browser or serve this directory with a static web server. Characters are saved locally in the browser. Export backups through Settings.

Includes the Mage, levels 1–5, Greyhaven, and the Sepulcher of the Forsaken with The Ebon Sentinel and The Mourning Lady.

## Deployment ownership

Repository deployments are managed exclusively through the EoA Deployment chat at the owner’s request. Other development chats should deliver build archives for deployment here.
